How It Works

2

Add Landed Costs

How to Use

FIRST — Assign User Access

Go to Settings → Users & Companies → Users. Ensure the user has the Inventory access group. No custom groups required.

1

Complete an Internal Transfer

Go to Inventory → Operations → Internal Transfers. Create and validate a warehouse-to-warehouse transfer. Once in Done state, it is eligible for landed cost allocation.

2

Create a Landed Cost

Go to Inventory → Valuation → Landed Costs → New. In the Transfers field, your internal transfers now appear alongside vendor receipts.

3

Add Cost Lines

Under Cost Lines, add each cost: freight, handling, insurance. Select a landed cost product or enter amounts manually. Each line needs a split method and account.

4

Validate & Review

Click Validate. The system creates SVL entries, posts journal entries, and updates AVCO product cost. Review the Valuation Adjustments tab and journal entry link.

Testing Guide

Verify every feature with these test scenarios.

Test 1: Equal Allocation

Transfer 3 products. Apply $300 with Equal split. Each product should get exactly $100 additional cost.

Test 2: By Quantity

Transfer 10 of A, 30 of B. Apply $400. A gets $100 (25%), B gets $300 (75%).

Test 3: Journal Entry

After validation, check the linked journal entry. Debits = Stock Valuation, Credits = Expense. Must balance.

Test 4: AVCO Price Update

Product at $100, 10 on hand. Apply $50 landed cost. Price should update to $105.
