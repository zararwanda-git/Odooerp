POS: Restrict Adding Products with Zero Quantity
This module adds a validation in the Odoo Point of Sale to prevent adding any item with zero available quantity.
If an item has no stock, the POS displays a warning popup and blocks the action.

Highlighted-features

Prevents Adding Zero-Stock Items
Instant Warning Popup on Selection
Avoids Accidental Sale of Unavailable Items

Detailed Features List

Zero-Stock Item Restriction

  • The module checks an item's available quantity in real time and blocks the action if the quantity is zero. Cashiers cannot add unavailable items to the order.

Enhanced User Experience with Manual Save Control

  • Whenever a zero-stock item is selected, a warning dialog appears, informing clear message to the cashier that the item cannot be added.

Prevents Accidental Unavailable Sales

  • Because the POS stops the item from being added, you avoid overselling or creating orders with unavailable products, improving accuracy and customer experience.

Consistent Behavior Across All Product Selections

  • Whether the cashier selects a normal product, variant or combo product inside the POS configurator, the restriction still applies.
